# SG-003A — MODBUS протокол калібратора FNIRSI

Репозиторій з документацією та інструментами для роботи з калібратором-генератором **FNIRSI SG-003A** через MODBUS RTU.

## Що таке SG-003A

Багатофункціональний калібратор, процесовий імітатор, генератор:
активний/пасивний струм 0–24 mA, напруга 0–24 V, частота 0–9999 Hz
(PWM, об/хв, кількість імпульсів), незалежне 24V живлення.

Внутрішній USB — STM32 Virtual COM Port (стандартний CDC, працює без драйверів,
у тому числі через OTG з Android-планшета). Швидкість порту — 115200.

## Головна особливість: фірмовий діалект MODBUS

Прилад **не підтримує стандартні функції** 03/04/2B — на них відповідає
exception 01 (Illegal Function). Замість них має власну таблиця функцій:

| Код | Hex | Призначення |
|---|---|---|
| 100 | 0x64 | читання |
| 101 | 0x65 | запис |
| 102 | 0x66 | читання |
| 103 | 0x67 | запис |

Кадрування при цьому стандартне MODBUS RTU (адреса + функція + дані + CRC16).

## Швидкий старт: перший робочий запит

Читання версії прошивки (slave 09, функція 0x64, реєстр 0x9C41):

```
09 64 9C 41 00 01 CE CC
```

- Термінал: **HEX-режим**, line ending = **None** (MODBUS RTU — бінарний протокол,
  зайві `\r\n` ламають кадр)
- Очікувана відповідь: `09 64 02 XX XX CRC`
- CRC перед відправкою звіряти онлайн-калькулятором
